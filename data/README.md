# Dataset Files

Official SemEval 2026 Task 2 dataset releases.

## 📦 Contents

### TRAIN_RELEASE_3SEP2025.zip (0.7 MB)
- Official training dataset
- Released: September 3, 2025
- Contains: Training samples with annotations

### TEST_RELEASE_5JAN2026.zip (0.45 MB)
- Official test dataset (without labels)
- Released: January 5, 2026
- Contains: Test samples for evaluation

### TEST_LABELS_RELEASE_23FEB2026.zip (0.1 MB)
- Test set labels
- Released: February 23, 2026
- Contains: Ground truth labels for test evaluation

## 🔗 References

- **Official Task**: SemEval 2026 Task 2 - Multimodal Sentiment Analysis
- **Task Website**: [SemEval Task Page]
- **Challenge Date**: 2026

## ✅ Usage

Extract all ZIP files to use the datasets:

```bash
unzip TRAIN_RELEASE_3SEP2025.zip
unzip TEST_RELEASE_5JAN2026.zip
unzip TEST_LABELS_RELEASE_23FEB2026.zip
```
